\subsection{Introduction}

The dream of a single language for mathematics, physics, biology, and computation has persisted at least since Leibniz''s \emph{characteristica universalis} and Whitehead and Russell''s \emph{Principia Mathematica}. Each attempt has foundered on a fundamental obstacle: the domains differ in scale, ontology, and methodology to such a degree that no single formalism has proven expressive enough without becoming vacuous. We propose a different strategy.

The Imscribing Grammar (IG) does not attempt to unify the \emph{theories} of these domains. Instead, it provides a \emph{taxonomy} --- a way of classifying any system, once described in its native language, into a 12-dimensional primitive space. Think of it as a periodic table for systems. A star, a proof, a neural network, and a cryptographic protocol are all different systems, but each can be assigned a synthon --- a 12-tuple of primitive values --- that captures its structural type. Once so assigned, the grammar provides algebraic tools for computing distances, composing systems, and identifying structural analogies across domains.

\begin{itemize}

    \item \textbf{Hamming distance} (\texttt{primitiveMismatches}): the count of component mismatches. A zero value iff the tuples are identical.
\end{itemize}

\subsection{Proof Engineering in Lean 4.28.0}

The formalization encountered numerous API subtleties in Lean 4.28.0 / Mathlib v4.28.0. Key lessons:

\begin{itemize}
    \item \texttt{Finset.sum\_map} (not \texttt{Finset.sum\_image}) must be used for \texttt{Nat.divisors\_prime\_pow}, which returns a \texttt{Finset.map} with a \texttt{Function.Embedding}, not a \texttt{Finset.image}.
    \item The \texttt{omega} tactic cannot cross \texttt{Finset.sum} barriers. The workaround is to introduce intermediate modular arithmetic steps that reduce to plain \texttt{ℕ} expressions.
    \item The geometric sum lemma \texttt{geom\_sum\_mul} lives in a \texttt{CommRing} (ℤ, not ℕ). The \texttt{zify} tactic --- with guards \texttt{{[}hp.one\_le, Nat.one\_le\_pow ...{]}} --- is the cleanest bridge between ℕ and ℤ.
    \item \texttt{norm\_num} primality extension requires \texttt{import Mathlib.Tactic}, not just targeted imports.
    \item Numeric rewrite chains (e.g., \texttt{rw {[}Nat.mul\_mod, hq{]}}) can fully close goals via \texttt{rfl} when the result is a closed numeral. Appending \texttt{norm\_num} after such a chain produces a ''''no goals'''' error --- omit it when \texttt{rw} already closes.
    \item The induction hypothesis in \texttt{suffices h : P n by ...} carries P n''s own hypotheses into the IH. Unconditional general lemmas must be factored out first.
\end{itemize}

    \begin{itemize}
    \item If $3 \nmid n$: modular arithmetic shows $n \equiv 1 \pmod{12}$.

\end{enumerate}
